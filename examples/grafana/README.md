# IronRoot Grafana Examples

These dashboards are starting points for local labs and platform teams. Import `ironroot-overview.json` and point panels at Prometheus, Tempo, and Loki data sources that match your environment.

Dashboard sections:

- API health
- Certificate issuance, renewals, revocations, active, and expiring certificates
- Enrollment failures and token validation failures
- Security-check failures
- DB latency
- Telemetry export health
