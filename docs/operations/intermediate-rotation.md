# Intermediate Rotation

<div class="ironroot-doc-meta" markdown>

Intermediate rotation creates a new Intermediate CA, imports it into IronRoot, marks it active, and lets existing certificates expire under the old issuer. Keep the Root CA offline during the signing step.
